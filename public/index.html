로그인 후 현재 접속의 승인 상태를 서버에서 확인합니다.

시험용 가상 기기는 로그인 세션 한 개입니다. 새 로그인은 별도 승인이 필요하며 실제 물리 기기 증명은 아닙니다.

앱 설치나 로그인만으로 기기 확인이 끝나지 않습니다. 실제 기기 확인과 접근 판정은 서버·접속 엔진이 맡습니다.

오프라인에서는 로그인·자료 조회·저장을 사용할 수 없습니다.

로그인과 서버의 시험 기기 승인이 모두 필요합니다. 승인 대기·철회·만료·확인 오류 때는 자료실이 잠깁니다.
